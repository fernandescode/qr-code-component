# QR Code Component

Meu projeto de estudo desenvolvido como parte do desafio **QR code component**, da plataforma [Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).

O objetivo foi reproduzir o componente apresentado no desafio utilizando HTML e CSS, praticando estruturação de páginas, estilização e responsividade.

## Prévia do projeto

![Prévia do QR Code Component](./preview.jpg)

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts — Outfit
- Git e GitHub para controle de versão

## O que aprendi

Durante o desenvolvimento, pratiquei:

- Centralização de elementos utilizando Flexbox.
- Controle de largura, margens, espaçamento e bordas com CSS.
- Ajuste da quebra de linha do texto para corresponder ao design de referência.
- Separação dos estilos em um arquivo CSS externo.
- Comparação do resultado com as referências para desktop e dispositivos móveis.
- Uso do Git para registrar as etapas do desenvolvimento.

## Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.
